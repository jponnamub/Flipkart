# FlipMart - Flipkart-inspired Ecommerce Storefront

FlipMart is a responsive, brand-neutral ecommerce storefront prototype inspired by large Indian marketplaces. It is built with plain HTML, CSS, and JavaScript so it can run locally without a build step.

## Features

- Sticky marketplace header with search suggestions, login, seller links, and cart counter
- Category ribbon for mobiles, fashion, electronics, home, appliances, beauty, grocery, and travel
- Rotating promotional hero banners and flash deal countdown
- Product grid with category, price, rating, assured, EMI, exchange, and delivery filters
- Sorting by popularity, price, rating, and discount
- Product detail modal with offers, highlights, seller, delivery, EMI, and exchange details
- Persistent wishlist and cart using local storage
- Cart drawer with quantity controls, price breakdown, discounts, delivery fee, address, payment, and order placement
- Pincode delivery checker, grocery and travel panels, Plus membership section, seller dashboard, support area, and footer
- Mobile-responsive menu, filters, layouts, and shopping flows

## Run locally

```bash
npm start
```

Then open `http://localhost:4173`.

## Check JavaScript syntax

```bash
npm run check
```
