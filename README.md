# Interview Agent Studio

A browser-only prototype for creating custom interview helper agents. Build
agents for specific roles, companies, stages, and goals, then use them to
generate reusable coaching prompts and practice plans.

## Features

- Custom interview agent builder
- Saved agent library using browser local storage
- Reusable prompt generator
- Practice workspace for flexible interview coaching requests
- Responsive static website with no build step

## Hosted website
